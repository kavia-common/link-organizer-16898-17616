# React Frontend

This project was bootstrapped with Create React App and Tailwind.

Premium dark theme UI is applied via CSS variables in src/App.css to provide a gradient/glass, GitHub-inspired look. The app includes:
- Fixed top navbar with app name and search
- Responsive dashboard grid cards
- Minimal profile and auth pages
- Accessible modals and components
- Optional Express backend integration and Supabase auth

Environment variables:
- REACT_APP_SUPABASE_URL
- REACT_APP_SUPABASE_KEY
- REACT_APP_SITE_URL (optional for email confirm redirect)
- REACT_APP_API_BASE (optional to use the Express backend)
